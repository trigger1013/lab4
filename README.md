## Завдання 1 — `my_system()`

Власна реалізація аналога стандартної функції `system()` без обробки сигналів.

**Алгоритм:**
1. `os.fork()` — створення дочірнього процесу.
2. У дочірньому: `os.execvp("/bin/sh", ["/bin/sh", "-c", command])` — запуск команди.
3. У батьківському: `os.waitpid(pid, 0)` — очікування та отримання коду завершення.

## Завдання 2 — Керування пулом дочірніх процесів

Створює задану кількість дочірніх процесів (за замовчуванням 10).
Кожен процес генерує число в [0, 1]:
- `>= 0.5` → завершується нормально
- `< 0.5` → виконує нескінченний цикл

Батьківський процес збирає завершені процеси, виводить список живих,
потім надсилає SIGTERM процесам, що залишились.

## Завдання 3 — Перевірка рівномірності розподілу ГПВЧ

`program0.py` — розбиває [0,1] на `n` рівних інтервалів, запускає `n` дочірніх
процесів (`program1.py`), збирає результати через коди повернення.

`program1.py` — NUM разів генерує число в [0,1], повертає кількість влучань
в свій інтервал [a, b] як код завершення (max 255).
